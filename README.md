# Desafio de Projeto: Criando meu Primeiro Repositório no GitHub

Repositório criado para registrar os primeiros passos e estudos práticos de Git e GitHub na formação da [DIO](https://www.dio.me).

## 🚀 O que aprendi neste projeto
* **Inicialização de Repositórios:** Como transformar uma pasta local em um repositório rastreável usando `git init`.
* **Fluxo de Trabalho do Git:** 
  * `git status` para verificar o estado dos arquivos.
  * `git add .` para adicionar alterações na área de staging.
  * `git commit -m "mensagem"` para salvar versões oficiais na linha do tempo local.
* **Integração com a Nuvem:** Como conectar o repositório local ao GitHub utilizando `git remote add origin` e enviar as atualizações com `git push origin main`.

## 🛠️ Tecnologias Utilizadas
* Git / GitHub
